Gripper Force Challenge

Can you pick up each object without dropping or crushing it? Set the grip force, then press Grip & Lift. Each object has different weight and fragility.

The physics: Your gripper squeezes with force F from both sides. Friction between jaws and object = F x friction coefficient. If friction force < object weight, it slips. If grip force > object's crush limit, it breaks. Find the sweet spot!
